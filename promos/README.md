# Plugin Store promo images

Marketing images for the Lock listing on the Craft Plugin Store, rendered in the same theme as the
plugin's marketing page at
[justinholt.com/plugins/craft-lock](https://justinholt.com/plugins/craft-lock).

## Building

```bash
./build.sh          # all slides
./build.sh "2 5"    # just slides 2 and 5
```

Output lands in `out/` as `lock-promo-N.jpg`, 1920×1080 (rendered at 2× in headless Chrome, then
downsampled so the type stays crisp). Promos ship as JPEG, never PNG; Chrome can only write PNG, so
`build.sh` converts each slide with `sips` and deletes the intermediate.

## Editing

Everything lives in `slides.html` — one `<section class="slide">` per image. The palette and fonts
are the plugin page's: accent `#CE8F5C`, deep `#8F5A30`, cool `#6FA396`, Jersey 20 for display,
Inter for body.

The charcoals are warm-shifted (`#191310`, not the usual `#101622`). A neutral or blue-shifted grey
next to this much brown reads as green, and the deck stops looking like one deck.

`assets/` holds the fonts and two icon files:

- `icon.svg` — the app icon, used for the cover mark and the footer lockup. Copy it from
  `../src/icon.svg` whenever the icon changes.
- `watermark.svg` — the padlock as a **silhouette**, sharing its geometry with `../src/icon-mask.svg`.
  Two things it deliberately is not: the app icon, whose tile is ~70px of solid colour at watermark
  scale and reads as a hard-edged box across the slide; and the icon's line art, whose 10/512 stroke
  disappears entirely at 5% opacity and leaves the slide empty. A mass survives the fade, an
  outline does not.

`fonts.css` is generated by `build.sh` (the woff2 files are base64-inlined so Chrome's `file://`
origin rules can't block them) and is not checked in.

## Two traps in this deck

**Slide 3's table is height-critical.** Seven rows only fit if every `.when` stays on one line. The
1fr column is about 880px at 25px Inter — roughly 70 characters. Edit a row's copy past that and it
wraps, the table grows ~34px, and the last row slides under the footer. There is no scrollbar and
no error; it just renders wrong.

**Prices appear in more places than this deck.** Changing `Free · Pro $149` on the cover means also
changing the page seed, `CLAUDE.md`, the README editions table, `docs/installation.md`, and the
edition prices at `id.craftcms.com` — which is the one that silently disagrees with everything else.

## Not legal advice

Lock quotes articles of the GDPR throughout, so the cover carries the line that it is a tool for
carrying out data protection decisions rather than a substitute for advice on what those decisions
should be. Keep it if you re-cut the deck — the same line appears in the page footer on
justinholt.com.
